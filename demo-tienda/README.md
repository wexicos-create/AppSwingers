# AppSwingers — tienda de membresías (vista previa)

Prototipo estático y navegable para revisar la presentación de AppSwingers sin crear una cuenta.

## Cómo verlo
Abre `index.html` en un navegador. No requiere instalación, cuenta, base de datos ni claves.

## Incluye
- Diseño adaptable a móvil y escritorio.
- Presentación de acceso gratuito, Prime y Gold.
- Selección de planes simulada en el navegador.
- Sección informativa para creadores.
- Avisos visibles de que no hay compras ni verificaciones reales.

## No incluye todavía
- Registro / inicio de sesión.
- Supabase, Firebase o base de datos.
- Didit/KYC o verificación de identidad.
- Stripe, Google Pay, SPEI/CEP ni pagos reales.
- Activación de membresías, panel administrativo o almacenamiento de datos.

Los importes con IVA son ilustrativos para la maqueta: Prime $350 + IVA = $406 MXN y Gold $500 + IVA = $580 MXN. Confirmar precios, tratamiento fiscal y beneficios antes de producción.

## Publicación pública
El repositorio actual es privado. Para que cualquier persona pueda abrir una URL pública sin iniciar sesión, el proyecto deberá publicarse desde un repositorio público y habilitar GitHub Pages, o desplegarse en un hosting estático gratuito. Esta rama no modifica `main`.
